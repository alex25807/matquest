**МатКвест** — интерактивный репетитор по математике для детей 9–12 лет (3–5 классы): квест, неоновый интерфейс и голосовое сопровождение. Задачи идут **от простого к сложному**, учат рассуждать (в том числе нестандартно), а не заучивать один шаблон.

Репозиторий: [https://github.com/alex25807/matquest](https://github.com/alex25807/matquest)

## 🌟 Особенности

### 🎯 Адаптивный квест (программа 4 класса)
- Генераторы задач по темам: **таблица умножения**, деление, движение \(S = v \cdot t\), дроби, площадь и периметр прямоугольника и квадрата
- Свой уровень сложности (тир) **по каждой теме**: три верных ответа подряд повышают ступень, две ошибки подряд — понижают
- Раунд из **7 задач**, сюжеты не повторяются подряд (в том числе задачи про теплоход не зацикливаются)
- **Две попытки**: после ошибки сразу не показывают ответ, дают наводящий вопрос
- После решения — короткое объяснение и иногда другой способ
- Тексты задач слегка подстраиваются под выбранную тему оформления

### ✖️ Таблица умножения (отдельный блок)
Кнопка на главном экране и в прогрессе. Лестница внутри блока:
1. **По порядку** — строка таблицы (например, на 7: 7×1, 7×2…)
2. **Вразнобой** — примеры и короткие сюжеты
3. **Наоборот** — деление и «найди множитель»
4. **Нестандартно** — разбиение на удобные части, сравнение произведений, полные группы с остатком

### 🎯 Определение уровня
- Входной тест из 10 вопросов
- Возраст 7–14 лет (класс подставляется автоматически)
- Уровни профиля от «Новичок» до «Магистр»
- **Два режима** входного теста: обычный и продвинутый
- **Графические задачи** в тесте (SVG): квадрат, прямоугольник и др. В адаптивном квесте составные «закрашенные» фигуры **не используются**

### 📐 Графические задачи
- Площадь квадрата, прямоугольника, треугольника
- Площадь круга, трапеции, ромба, параллелограмма
- Составные фигуры (комбинации простых фигур)
- Визуальное отображение с размерами

### ⭐ Продвинутый режим
- Уравнения с одной переменной
- Теорема Пифагора
- Числа Фибоначчи и последовательности
- Системы уравнений
- Дроби со сложными вычислениями
- 6-й уровень "Магистр"

### 🧩 Головоломки (отдельный режим!)
**30 уникальных головоломок** для развития нестандартного мышления:
- 🧩 **Логические загадки** — задачи на внимательность и логику
- 🔢 **Числовые головоломки** — магические квадраты, загадки с числами
- 📐 **Пространственные** — задачи на воображение и 3D-мышление
- 💡 **Нестандартные** — задачи, где нужен нестандартный подход
- 🎭 **Обманки** — задачи с подвохом, учат внимательности
- 👁️ **Визуальные** — головоломки с фигурами и образами
- 🧠 **На смекалку** — задачи на сообразительность

**Возможности режима:**
- Выбор категории головоломок
- Случайный набор из 7 головоломок
- Подсказки для каждой головоломки
- Повышенный XP за решение (15 XP)
- Подробные объяснения решений

### 🎨 4 темы оформления на выбор
1. **⛏️ Майнкрафт** - строй мир знаний блок за блоком
2. **🚀 Тайна 3-й планеты** - исследуй космос чисел и формул
3. **🕷️ Человек-паук** - твоя суперсила - математика!
4. **🐉 Как приручить дракона** - приручи дракона математики!

### 🎮 Игровая механика
- Система опыта (XP) и уровней
- Достижения и награды
- Серии правильных ответов с бонусами
- Конфетти и анимации за успехи
- Мотивационные сообщения и факты о знаменитых людях

### 🔊 Голосовое сопровождение
- Озвучка вопросов и ответов
- Похвала за правильные ответы
- Поддержка при ошибках
- Настройка скорости речи
- Возможность отключения звука

### 💾 Сохранение прогресса
- Все данные сохраняются в localStorage
- Отслеживание статистики
- История тестов
- Система достижений

### 🧠 Умные подсказки и альтернативные решения

**Многоступенчатые подсказки:**
- 3 уровня подсказок для каждой задачи
- От общих наводящих вопросов к конкретным указаниям
- Стимулируют самостоятельный поиск решения
- Развивают навык самообучения

**Альтернативные способы решения:**
- 2-3 разных способа решения каждой задачи
- Показывают, что математика — это творчество
- Развивают гибкость мышления
- Помогают найти "свой" подход к задачам

## 📖 Инструкция по использованию

### 1. Первый запуск

1. Откройте приложение в браузере
2. Нажмите **"🚀 НАЧАТЬ ПРИКЛЮЧЕНИЕ"**
3. Введите имя ребёнка
4. Выберите возраст (7-14 лет) - программа автоматически определит класс
5. Выберите тему оформления (Майнкрафт, Космос, Человек-паук или Драконы)
6. Нажмите **"🚀 НАЧАТЬ!"**

### 2. Тестирование уровня

После регистрации автоматически запускается тест из 10 вопросов:
- Вопросы разного уровня сложности
- Мгновенная обратная связь после каждого ответа
- Объяснения правильных ответов
- Мотивационные сообщения
- Факты о знаменитых людях (каждые 3 правильных ответа)

По результатам теста определяется начальный уровень (1-5).

### 3. Прохождение квеста

1. **МОЙ ПРОГРЕСС** → **КВЕСТ** — смешанный раунд (таблица, деление, движение, дроби, площадь)
2. **ТАБЛИЦА УМНОЖЕНИЯ** — только тренировка таблицы (по порядку → вразнобой → наоборот)
3. Ответ вводится **числом**. Если ошибся — наводящий вопрос и вторая попытка; готовый ответ открывается только после неё
4. За верный ответ: **12 XP** с первой попытки, **6 XP** со второй
5. Три верных подряд по одной теме открывают более сложный тип задач этой темы
6. Раунд — **7 задач**, затем итог и выход в меню

### 4. Система прогресса

**Уровни:**
- 🪵 Уровень 1: Новичок
- ⛏️ Уровень 2: Ученик
- 💎 Уровень 3: Знаток
- 🏰 Уровень 4: Мастер
- 🌟 Уровень 5: Гуру
- 👑 Уровень 6: Магистр (продвинутый режим)

**Режимы сложности:**
- 📘 **Обычный** — базовые задачи по арифметике, геометрии и логике
- ⭐ **Продвинутый** — уравнения, теорема Пифагора, дроби, последовательности + графические задачи

**Опыт (XP):**
- 12 XP за верный ответ с первой попытки, 6 XP со второй
- 15 XP за головоломку
- 100 XP нужно для повышения уровня профиля

### 5. Настройки

Нажмите **"⚙️ НАСТРОЙКИ"** на главном экране:
- Измените имя и возраст
- Включите/выключите голосовое сопровождение
- Настройте скорость речи
- Протестируйте голос
- (Опционально) Подключите Yandex SpeechKit API

### 6. Смена темы

1. Нажмите **"🎨 СМЕНИТЬ ТЕМУ"**
2. Выберите одну из 4 тем
3. Тема сохранится в профиле

### 7. Головоломки

Нажмите **"🧩 ГОЛОВОЛОМКИ"** на главном экране или в экране результатов:

1. **Случайные головоломки** — нажмите кнопку для получения набора из 7 случайных головоломок
2. **Категории** — выберите конкретный тип головоломок:
   - 🧩 Логические — задачи на внимательность
   - 🔢 Числовые — магические квадраты, последовательности
   - 📐 Пространственные — задачи на воображение
   - 💡 Нестандартные — требуют нестандартного подхода
   - 🎭 Обманки — задачи с подвохом
   - 👁️ Визуальные — головоломки с фигурами
   - 🧠 Смекалка — задачи на сообразительность
3. Решайте головоломки, получайте подсказки и объяснения
4. За каждую разгаданную головоломку — 15 XP!

### 8. Статистика и достижения

Нажмите **"📊 МОЙ ПРОГРЕСС"** чтобы увидеть:
- Текущий уровень и опыт
- Процент точности ответов
- Количество решённых задач
- Текущую серию правильных ответов
- Заработанные достижения

### 8. Выход

Нажмите **"🚪 ВЫЙТИ"** на главном экране для выхода из приложения.

## 🎓 Методики обучения

### Психологические приёмы
- **Позитивное подкрепление**: похвала за каждый правильный ответ
- **Мотивация через примеры**: истории успешных людей (Илон Маск, Эйнштейн, Королёв)
- **Игровая форма**: квест, уровни, достижения
- **Поддержка при ошибках**: ободрение вместо критики
- **Визуальные награды**: конфетти, анимации, неоновые эффекты

### Педагогические подходы
- **От простого к сложному**: тиры внутри темы и разминка с таблицы в начале раунда
- **Наводящий вопрос, не готовый ответ**: ребёнок сам собирает способ решения
- **Разнообразие сюжетов**: один приём (например, пропорциональность) не кормят пачкой одинаковых «теплоходов»
- **Обратные действия**: умножение ↔ деление в блоке таблицы
- **Нестандартные ходы** на верхней ступени: разбиение произведения, сравнение, остаток
- **Короткое занятие**: 7 задач за раунд
- **Объяснение после решения**: и при успехе, и после второй ошибки — с другим способом, если он есть

## 🎤 Интеграция с Yandex SpeechKit и Yandex GPT

Для подключения голосового синтеза от Яндекс и ИИ:

1. Получите API-ключ в [Yandex Cloud Console](https://console.cloud.yandex.ru/)
2. Создайте сервисный аккаунт с ролью `ai.speechKit.tts.user` и `ai.languageModels.user`
3. В настройках приложения введите:
   - API-ключ
   - Folder ID
4. Отредактируйте `src/hooks/useSpeech.ts` и `src/data/yandexConfig.ts`

**Примечание**: По умолчанию используется встроенный Web Speech API браузера.
