# 📤 Инструкция по загрузке проекта на GitHub

## 🎯 Быстрый способ (через браузер)

### Шаг 1: Скачайте архив проекта

**Вариант А: Через интерфейс платформы**
- Найдите кнопку **"Download"** или **"Скачать"** в окне предпросмотра
- Обычно это иконка ⬇️ или в меню ⋮ (три точки)
- Скачается ZIP-архив со всеми файлами

**Вариант Б: Если есть доступ к терминалу**
```bash
# Создайте архив (исключая node_modules)
zip -r matquest.zip . -x "node_modules/*" -x ".git/*" -x "dist/*"
```

### Шаг 2: Загрузите на GitHub

1. **Распакуйте ZIP-архив** в отдельную папку

2. **Перейдите в репозиторий:**
   - Откройте [https://github.com/alex25807/matquest](https://github.com/alex25807/matquest)
   - Нажмите **"uploading an existing file"** или **"Add file" → "Upload files"**

3. **Перетащите ВСЕ файлы** из распакованной папки в окно браузера:
   - Все файлы из корня (package.json, README.md, и т.д.)
   - Папку `src/`
   - Папку `public/`
   - Папку `.github/`
   - Файлы `.gitignore`, `LICENSE`, `CONTRIBUTING.md`, `GITHUB_SETUP.md`
   - **НЕ загружайте** папку `node_modules/` (она уже в .gitignore)

4. **Нажмите "Commit changes"** внизу страницы

### Шаг 3: Дождитесь автоматического деплоя

- GitHub Actions автоматически запустит сборку
- Через 1-2 минуты сайт будет доступен по адресу:
  **https://alex25807.github.io/matquest**

## 🔧 Альтернативный способ: через Git (для продвинутых)

Если у вас установлен Git:

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/alex25807/matquest.git
cd matquest

# 2. Скопируйте файлы проекта в эту папку
# (распакуйте ZIP и скопируйте всё, кроме node_modules)

# 3. Добавьте файлы
git add .

# 4. Сделайте коммит
git commit -m "Initial commit: МатКвест - интерактивный репетитор по математике"

# 5. Отправьте на GitHub
git push origin main
```

## ✅ Проверка деплоя

1. Перейдите в репозиторий на GitHub
2. Откройте вкладку **"Actions"**
3. Вы должны увидеть запущенный workflow "Deploy to GitHub Pages"
4. Дождитесь завершения (зелёная галочка ✓)
5. Откройте **https://alex25807.github.io/matquest**

---

## 🐛 Если что-то пошло не так

### Проблема: Сайт не открывается
**Решение:** Подождите 2-3 минуты. GitHub Pages требует время на деплой.

### Проблема: Ошибка сборки
**Решение:** 
1. Проверьте вкладку "Actions" в репозитории
2. Посмотрите логи ошибки
3. Убедитесь, что все файлы загружены корректно

### Проблема: Страница 404
**Решение:**
1. Убедитесь, что в Settings → Pages выбран источник "GitHub Actions"
2. Проверьте, что workflow завершился успешно
