# 🤝 Руководство по участию в проекте

Спасибо за интерес к проекту МатКвест! Мы рады любому вкладу — от исправления опечаток до добавления новых функций.

## 📋 Как внести вклад

### 1. Форк репозитория
1. Нажмите кнопку "Fork" в правом верхнем углу
2. Клонируйте форк на свой компьютер:
```bash
git clone https://github.com/YOUR_USERNAME/matquest.git
cd matquest
```

### 2. Создайте ветку
```bash
git checkout -b feature/название-вашей-фичи
# или
git checkout -b fix/описание-исправления
```

### 3. Внесите изменения
- Следуйте существующему стилю кода
- Добавляйте комментарии к сложным местам
- Тестируйте изменения локально

### 4. Закоммитьте изменения
```bash
git add .
git commit -m "Описание изменений"
```

Используйте понятные сообщения коммитов:
- `feat: добавлена новая тема "Звёздные войны"`
- `fix: исправлена ошибка с голосовым синтезом`
- `docs: обновлён README`
- `style: форматирование кода`

### 5. Отправьте в GitHub
```bash
git push origin feature/название-вашей-фичи
```

### 6. Создайте Pull Request
1. Перейдите в ваш форк на GitHub
2. Нажмите "Pull Request"
3. Опишите ваши изменения
4. Дождитесь ревью

## 📝 Добавление новых вопросов

Файл: `src/data/questions.ts`

Формат вопроса:
```typescript
{
  id: 'уникальный_id',
  topic: 'arithmetic' | 'multiplication' | 'division' | 'fractions' | 'geometry' | 'logic',
  level: 1-5,
  question: 'Текст вопроса',
  options: ['Вариант 1', 'Вариант 2', 'Вариант 3', 'Вариант 4'],
  correct: 0-3, // индекс правильного ответа
  explanation: 'Объяснение правильного ответа',
  hint: 'Подсказка (опционально)'
}
```

**Рекомендации:**
- Используйте игровой контекст для тем
- Давайте понятные объяснения
- Добавляйте подсказки для сложных задач
- Проверяйте правильность ответов

## 🎨 Добавление новой темы

1. Добавьте тему в `src/types.ts`:
```typescript
export type Theme = 'minecraft' | 'space' | 'spiderman' | 'dragon' | 'your_theme';
```

2. Добавьте стили в `src/index.css`:
```css
.theme-your_theme {
  background: linear-gradient(135deg, ...);
}
```

3. Добавьте эмодзи и описания в компоненты:
- `StartScreen.tsx`
- `NewGameScreen.tsx`
- `QuestScreen.tsx`
- `ResultsScreen.tsx`

4. Добавьте мотивационные сообщения в `src/data/motivation.ts`:
```typescript
themeGreetings: {
  your_theme: [
    "Приветствие 1",
    "Приветствие 2",
    "Приветствие 3"
  ]
}
```

## 📏 Стиль кода

- Используйте TypeScript
- Следуйте существующей структуре файлов
- Именование компонентов: PascalCase
- Именование функций: camelCase
- Именование констант: UPPER_SNAKE_CASE
- Добавляйте типы для всех props

## 🧪 Тестирование

Перед отправкой PR:
```bash
# Проверка типов
npm run typecheck

# Сборка проекта
npm run build

# Запуск dev-сервера
npm run dev
```

Проверьте:
- Все страницы работают
- Нет ошибок в консоли
- Адаптивность на разных экранах
- Голосовой синтез работает
